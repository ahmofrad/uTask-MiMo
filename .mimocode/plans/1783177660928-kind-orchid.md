# Plan: Comprehensive Test Suite

## Approach
Write tests in waves, prioritizing security-critical paths first. Each wave is independently committable. All tests use existing vitest + Playwright infrastructure with the same patterns as existing tests (no mocking libraries, pure function testing, regex-based locators for E2E).

---

## Wave 1: Security-critical unit tests (7 files)

### `tests/unit/crypto/hash.test.ts`
- `sha256("hello")` returns expected hex
- `sha256("")` returns empty hash
- `sha256Buffer` returns Buffer of correct length

### `tests/unit/crypto/hmac.test.ts`
- `hmacSign(payload, secret)` returns consistent hex string
- `hmacVerify(payload, signature, secret)` returns true for valid
- `hmacVerify` returns false for tampered payload
- `hmacVerify` returns false for wrong secret
- Timing-safe comparison is used (not `===`)

### `tests/unit/crypto/encrypt.test.ts`
- `encrypt(text)` returns `{ iv, ciphertext, tag }` — all non-empty strings
- `decrypt(encrypt(text))` roundtrips correctly
- `encrypt` produces different output each call (random IV)
- Wrong key throws decryption error

### `tests/unit/api-token/index.test.ts`
- `generateToken()` returns `{ raw, hash, prefix }` — raw is 64-char hex, prefix is first 8 chars
- `createApiToken()` stores hashed token, returns raw + prefix
- `lookupToken(raw)` finds the correct token by hash
- `lookupToken` returns null for invalid token
- `revokeToken` sets revokedAt, subsequent `lookupToken` returns null

### `tests/unit/rate-limit/index.test.ts`
- Under limit: returns `{ allowed: true, remaining: N }`
- Over limit: returns `{ allowed: false, remaining: 0 }`
- Different keys have separate counters
- Window reset after `windowMs` passes

### `tests/unit/idempotency/index.test.ts`
- `checkIdempotency` returns `{ hit: false }` for new key
- `setIdempotencyResult` + `checkIdempotency` returns cached response
- Expired entries return `{ hit: false }` (mock time)

### `tests/unit/webhook/index.test.ts`
- `validateWebhookUrl("https://example.com")` returns true
- `validateWebhookUrl("http://example.com")` returns false (no HTTPS)
- `validateWebhookUrl("http://localhost:3000")` returns false (private)
- `validateWebhookUrl("http://192.168.1.1")` returns false (private IP)
- `validateWebhookUrl("https://internal.company.local")` returns false
- `signPayload` + `verifySignature` roundtrip works
- `decryptSecret("iv:ciphertext:tag")` decrypts correctly
- `decryptSecret("legacy-plaintext")` returns as-is
