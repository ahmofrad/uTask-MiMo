## 4. Rate Limiter → Redis-backed
**Files:** `src/lib/rate-limit/index.ts`

- Replace in-memory Map with Redis-backed sliding window using ioredis
- Three tiers: per-IP (unauthenticated, 100 req/min), per-user (session, 300 req/min), per-token (public API, 1000 req/min)
- Add middleware that applies rate limiting to all `/api/` routes
- Return `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset` headers
- Keep in-memory fallback when Redis is unavailable (dev mode)

## 5. Worker Improvements
**Files:** `src/worker.ts`, `src/lib/queue/index.ts`

- Add `failed` event handler on workers for error logging

- Fix connection race condition: use a single shared promise for Redis connection
- Measure actual webhook dispatch duration instead of hardcoding 0
- Add dead-letter logging: after final failure, log to audit with `action: "webhook_delivery_failed"`
