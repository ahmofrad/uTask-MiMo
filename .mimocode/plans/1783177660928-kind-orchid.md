# Plan: Task/Project Members, Assignee, and Related Features

## Current Gaps (from exploration)

1. **Assignee picker broken** — dropdown exists in task detail but has zero user options
2. **No project member removal** — no DELETE endpoint for members
3. **Auto-watch never invoked** — assignee/reporter/commenter never auto-subscribed
4. **Notifications never sent** — `createNotification` exists but is never called
5. **"+ Add member" button broken** — no onClick handler
6. **Task filters missing assignee** — type exists but no UI dropdown
7. **Task list shows UUID slices** instead of user names
8. **Project settings has no save handler**
9. **No validation** that assignee is a project member

## Phase 1: Fix Assignee Selection

### 1a. Task detail page — populate assignee dropdown
`src/components/task/task-detail-page.tsx`:
- Pass `projectMembers` (id, displayName) as prop from server page
- Render member options in the assignee `<select>`
- On change → PATCH `/api/v1/tasks/:id` with `assigneeId`

### 1b. Task form — add assignee picker
`src/components/task/task-form.tsx`:
- Accept `projectMembers` prop
- Add assignee select dropdown to the form
- Include `assigneeId` in handleSubmit data

### 1c. Task creation page — pass members
`src/app/[locale]/(app)/projects/[projectId]/page.tsx` and `dashboard/page.tsx`:
- Fetch project members and pass to task form

## Phase 2: Project Member Management

### 2a. Members page — wire up add/remove
`src/app/[locale]/(app)/projects/[projectId]/members/page.tsx`:
- Make it a client component or extract a client wrapper
- Wire up "+ Add member" button → user search/select → POST `/api/v1/projects/:id/members`
- Add remove button per member → DELETE `/api/v1/projects/:id/members/:userId`

### 2b. Members API — add DELETE endpoint
`src/app/api/v1/projects/[id]/members/[userId]/route.ts` (NEW):
- DELETE handler: remove project member
- RBAC: project lead or global admin can remove
- Audit log on removal

### 2c. Project detail — show member avatars
`src/components/project/project-detail-page.tsx`:
- Show member avatars in header (already has data, just render it)

## Phase 3: Auto-Watch + Notifications

### 3a. Auto-watch on assignment
`src/lib/tasks/mutations.ts`:
- When `assigneeId` changes → call `ensureWatcher(taskId, assigneeId)`
- When task is created with assignee → auto-watch

### 3b. Auto-watch on comment
`src/app/api/v1/tasks/[id]/comments/route.ts`:
- After creating comment → auto-watch the commenter on the task

### 3c. Send notification on assignment
`src/lib/tasks/mutations.ts`:
- When assignee changes → `createNotification({ userId, type: "assigned", ... })`

## Phase 4: Task Filters + UI Polish

### 4a. Task filter — add assignee dropdown
`src/components/task/task-filters.tsx`:
- Add assignee select populated with project members
- Wire to filter state

### 4b. Task list — show user name/avatar
`src/components/task/task-list.tsx`:
- Use `task.assignee.displayName` instead of UUID slice

### 4c. i18n — translate members page
- All hardcoded English on members page → translation keys
