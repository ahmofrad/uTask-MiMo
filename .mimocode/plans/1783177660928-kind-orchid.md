# Plan: Login Page Redesign

## Goal
Redesign login page with conditional SSO/LDAP buttons, language picker, better design, and fix all i18n issues.

## Files to modify

### 1. `src/components/auth/login-form.tsx` — rewrite with conditional fields
- Accept props: `ldapConfigured: boolean`, `ssoConfigured: boolean`, `ldapDomainName: string`
- If LDAP configured: show provider dropdown (Local / LDAP domain name) below password field
- If SSO configured: show SSO button below the "or" divider
- If neither configured: just email + password + forgot password + login button (no divider, no SSO)
- Fix forgot password label — currently uses `t("forgotPassword") || "Forgot password?"`, make it always use the translation key
- Fix all hardcoded strings to use translation keys

### 2. `src/app/[locale]/(auth)/login/page.tsx` — redesign with better layout
- Fetch LDAP/SSO config from settings table (server-side)
- Add language picker (locale switcher) in the top-right corner
- Better card design: centered logo, subtle gradient background, cleaner spacing
- Remove hardcoded "Welcome back. Sign in to continue." — use i18n
- Pass LDAP/SSO config to LoginForm as props

### 3. `src/app/[locale]/(auth)/layout.tsx` — add language picker
- Add a small language toggle button in the corner (RTL-aware positioning)

### 4. `src/messages/en-US.json` and `src/messages/fa-IR.json` — add missing keys
- `auth.login.forgotPassword` — ensure it exists
- `auth.login.welcomeBack` — "Welcome back. Sign in to continue."
- `auth.login.localLogin` — "Local login"
- `auth.login.ldapDomain` — LDAP domain name display
- `auth.login.noSso` — hide divider when no SSO
- `auth.login.divider` — "or"

### 5. Design improvements
- Subtle gradient or pattern background instead of flat color
- Logo with icon or SVG
- Cleaner card with better shadow and border radius
- Smooth hover transitions on buttons
- Better error state styling

## Verification
- Without LDAP/SSO: email + password + forgot password + login button only
- With LDAP: dropdown appears (Local / Domain name)
- With SSO: SSO button appears below divider
- Language picker works and switches locale
- All text uses i18n keys
- Forgot password link works
- Login form submits correctly for all providers
