# Plan: Make Activity Timeline Fully Spec-Compliant

## Goal
Fix all issues in the task activity timeline to meet the spec: i18n, type safety, RTL, live refresh, pagination, readable diffs, shared data layer, RBAC, filtering, and Icon wrapper.

### 2. `src/components/task/activity-timeline.tsx` — major rewrite
Changes:
- **i18n**: Replace `event.action.replace(/_/g, " ")` with `t("audit.actions." + event.action)` fallback to raw action
- **RTL**: Change `left-[11px]` → `start-[11px]` on timeline line
- **Type safety**: Remove any `as any` usage
- **Readable diffs**: Replace `JSON.stringify` with a `DiffView` sub-component that shows field-by-field before/after comparison (field name translated, values truncated)
- **Icon wrapper**: Wrap SVG icons with a helper or use the existing `<Icon>` pattern if available, otherwise use a clean helper component

### 3. `src/components/task/task-detail-page.tsx` — wire up activity
Changes:
- **Remove `as any`**: Fix the type mismatch by properly mapping `auditEvents` in the server page
- **Live refresh**: After `updateTask` mutations (status, priority, title, description, assignee, dueDate), fetch latest audit events and prepend new ones to state
- **Load more**: Implement `handleLoadMore` that fetches next page from `/api/v1/activity/tasks/[taskId]` using the cursor, append to existing events
- **State management**: Track `auditCursor` and `auditHasMore` in state

### 4. `src/lib/activity/index.ts` — fix RBAC and data layer
Changes:
- **Fix RBAC**: Replace `can(userId, "task:edit_any")` with a project-membership check (fetch task's projectId, then check `canProject` with a read-level permission)
- **Populate `details`**: Add `beforeJson`/`afterJson` to the audit log query mapping (currently missing)
- **Export a `getTaskActivityCount`** or use existing meta for hasMore detection

### 5. `src/app/[locale]/(app)/tasks/[id]/page.tsx` — use shared data layer
Changes:
- Replace direct `prisma.auditLog.findMany` with `getTaskActivity(taskId, userId, { limit: 100 })`
- This ensures consistent RBAC, data shape, and pagination support
- Remove `as any` since data now matches `ActivityEvent[]` type

### 6. `src/lib/activity/types.ts` — minor type improvements
Changes:
- Type `action` as `AuditAction` from Prisma instead of `string`
- Add optional `requestId?: string` field to `AuditEvent`
